# OpenFlashAir 0.1.0

Initial Windows release candidate: manual and automatic photograph synchronization, thumbnail browsing, prioritized selection, image preview and metadata, connection settings, and a notification-area menu.

The Windows installer is unsigned. Verify its origin and published checksum; Windows may display a security warning. W-04 has been tested; W-03 is expected to work but is untested, and W-02/W-01 compatibility is unknown. Other operating systems are not currently supported.

Third-party components are subject to separate license terms; see [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). This draft release remains subject to the native-library redistribution review described there.
