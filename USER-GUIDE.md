# Installation and use

1. Download the installer from the official GitHub release and compare its SHA-256 checksum with the published checksum.
2. Run the installer, choose whether to create a desktop shortcut, and launch OpenFlashAir. The current candidate is unsigned; Windows may show a warning. Do not bypass a warning without verifying the download's origin and checksum.
3. Connect Windows to the FlashAir network or the network hosting the card. Choose a destination folder, check the connection, and use Scan Once to download photographs. Auto Scan can repeat this process.
4. Use the gallery to preview and select eligible photographs. Existing verified downloads are skipped; retain your own independent photo backups.
5. Connection Settings edits a physically mounted card's CONFIG only after confirmation. Back up the original CONFIG before changing settings; changing Wi-Fi settings may disconnect the card. Keep backups private because they may contain credentials.
6. Close the window to exit, or minimize to the notification area where available. Use the tray menu to restore or exit.

The installer is designed to leave user settings, history and downloaded photos outside the installation directory. Back up important data before upgrades or uninstall. Exact Windows version support and clean-machine upgrade/uninstall behavior require release qualification. Internet access is not inherently required for a direct local connection, but network and card configuration must permit communication.
